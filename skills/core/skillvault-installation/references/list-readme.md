# SkillVault List

List global and all discovered project skill folders with stable indexes for the current command run. Folders without `skill.json` are shown as unmanaged.
Uninstall selected skills by index, comma list, range, or keyword.

Examples:

```text
/skillvault-installation list
/skillvault-installation list
/skillvault-installation list project
/skillvault-installation list session
/skillvault-installation list uninstall 2
/skillvault-installation list uninstall 2
/skillvault-installation list uninstall 1,3-5
/skillvault-installation list uninstall sync
```
